# Which package may import which, inside this module.
#
# docs/layout.md is where these rules are argued. This file is the rule and
# internal/importrules is what refuses a violation, so the note explains and
# nothing depends on somebody having read it.
#
# One line per package, written as its path from the module root. What follows
# the colon is the complete set of packages inside this module that its files
# may import, and an import that is not on the line is refused. A package in
# the tree with no line here is refused as well, so this file cannot fall
# behind the tree by being forgotten.
#
# A permission list rather than a list of forbidden edges, because the edge
# that matters is the one nobody thought of. Several rules below are therefore
# carried by what a line does not say, and each of those lines says so above
# itself rather than leaving a reader to notice an absence.
#
# "<package> +test:" adds what that package's own test files may import on top
# of its line. A test file may import the package it tests without any line
# saying so, which is what an external test package does.
#
# "planned <package> <reference>" declares a package that is not in the tree
# yet, carrying the issue that creates it. It is a debt rather than a place to
# hide one: the day the package lands, the marker is stale and the check says
# so. A line naming a package that is neither in the tree nor planned is
# refused as a typo.
#
# "test-only <package> <reference>" says that nothing which ships may import
# it. A shipped line naming one is refused when this file is read, before any
# tree is looked at.

# The permission model, and what these three lines carry is again the absence.
#
# internal/authz resolves a permission set, and it imports nothing from this
# module. A resolver that could reach a store, a source or an identity provider
# is one that can answer a question by going and asking, and the whole point of
# the resolution in docs/decisions/0003 is that it is a decision over facts
# already gathered. Deny wins and unknown means deny only mean anything if
# nothing can be fetched to turn an unknown into something else.
#
# internal/auth turns what a provider said into a principal, and internal/audit
# declares the record shape. Both reach internal/authz and nothing else. Neither
# imports the datastore or the retrieval package: a principal that could load
# its own permissions, or an audit record that could read the index it is
# recording a decision about, puts a second route to that data beside the one
# the filter is inside.
internal/authz:
internal/auth: internal/authz
internal/audit: internal/authz
